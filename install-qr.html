TAG

Point an Android phone's camera at this code to install the app.

Scan to install
v0.1.0 SDK 57 Android APK OTA enabled
  1. Scan with the phone's normal Camera app — it opens the download.
  2. Tap the downloaded file to install.
  3. Android will say the app is from an unknown source — allow it. That's normal for any APK outside the Play Store.
  4. Open Tag. It should land straight on the camera.

Android only. iPhones can't install an APK — that needs Apple's $99/yr Developer Program, so iPhone users still go through Expo Go for now.
