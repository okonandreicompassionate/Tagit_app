What this page can't show you

It reads the database as an ordinary signed-out user, using the same public key the app ships with. That means it can only ever see what any user could: public events, cards, and the aggregate leaderboards. Scans, check-ins, friendships and payments stay invisible — row-level security hides them, which is the point.

Seeing those needs a server that holds the service_role key, never a page like this one. See docs/ADMIN.md.
