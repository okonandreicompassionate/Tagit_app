Tagit — test codes

Display this page on your monitor and scan the codes with Tagit on your phone. You can't scan your own phone's screen, so this stands in for a second person.

These resolve only after npm run db:push has seeded the demo cards. Before that, a scan returns “No card behind that code”.

Each code encodes https://tagit.app/u/<id> — the same short URL the app generates for you. Scan one, and you should get the profile sheet with a swag toast, an Add on Snap button, and the person appearing in your Tagged list. Scan the same one twice in a day and the second scan should be worth less, with no streak awarded.
